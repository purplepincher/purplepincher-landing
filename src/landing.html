SuperInstance is a ~4,100-repo research sketchbook — one person thinking out loud in code, fast and uneven and honest about being uneven. PurplePincher is the shell an idea moves into once it has been built for real, tested against its actual use, and stripped of the speculative framing it was born inside.

What this account actually is, one hop from anywhere in it

The repo ledger above accounts for code. This accounts for the live sites built from it — sixteen domains, each tagged by what kind of thing it is, not narrated into one story. This isn't one story wearing sixteen faces. It's one discipline — build a real, narrow thing, say plainly what it is — applied wherever the org owner found a field worth trying it in. The coherence is the discipline, not a plot.

How a repo earns the shell

  • Verified working, end-to-end — exercised through its real use case, not "has tests." SuperInstance's own CI has been caught running pytest || true. That is banned here.
  • Docs rewritten to match reality — every claimed feature exists; every example runs; every install command works.
  • Speculative framing stripped to optional — where the underlying math is real, it's presented as what it actually is.
  • Published — crates.io, PyPI, or npm, under the name the README uses.
  • Scoped — a stated boundary of what it will not do.
